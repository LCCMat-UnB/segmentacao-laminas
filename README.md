# Atividade realizada por Larissa

### Objetivo da atividade 

Iniciar o aprendizado para construção de redes neurais por meio de uma rede neural simples de classificação de imagens como gato ou não-gato.

```
Fluxo 1: dados → rede neural → treinamento → resultado → uma alteração → comparação
```

### Divisão da atividade por seções
---

1. Conhecendo o dataset
2. Separação de dados para treino e teste
3. Preparação dos dados
4. Organização dos dados para treinamento
5. Criação de rede neural
6. Configuração do treinamento
7. Treinando o baseline
8. Vendo o resultado
9. Fazendo alterações
10. Comparação
